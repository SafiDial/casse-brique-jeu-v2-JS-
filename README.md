# 🎮 Casse-Brique en JavaScript

Bienvenue sur mon petit jeu **Casse-Brique** développé en **HTML**, **CSS** et **JavaScript**.

👉 [Clique ici pour jouer](https://safidial.github.io/casse-brique-jeu-v2-JS-/)

## 🎯 Objectif du jeu

- Casser toutes les briques sans perdre toutes tes vies.
- Tu as **3 vies** au départ. Le jeu affiche **"PERDU"** quand elles sont toutes utilisées.
- Clique sur **Commencer** pour démarrer la partie.
- Si tu perds, le bouton change en **Recommencer**.

## ✨ Fonctions principales

- Briques en **dégradé or/jaune**
- Balle avec effet de **dégradé**
- Animation fluide avec **Canvas**
- Interface 100% en **français**
- Design responsive (s’adapte aux écrans)

## 🚀 Technologies utilisées

- HTML5
- CSS3
- JavaScript (Canvas API)
